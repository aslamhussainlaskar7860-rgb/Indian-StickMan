GitHub par upload steps:
1. github.com par New repository banao (naam: indian-stickman), Public.
2. "uploading an existing file" par click karo aur is folder ki SAARI files + icons folder drag-drop karo. Commit karo.
3. Settings -> Pages -> Source: Deploy from branch -> main / (root) -> Save.
4. 1-2 minute baad link milega: https://USERNAME.github.io/indian-stickman/
5. Phone par link kholo -> INSTALL GAME button / Chrome menu -> Install app.
